PROFILE | FEATURES & TUTORIALS

Rig presets, tool explanations and a practical start-to-finish workflow.

QUICK START

From mesh to motion

PROFILE is a character rigging and animation workspace. Load a supported model, choose a rig preset, build the skeleton and skin binding, pose with FK or IK, create motion, refine keyframes, then export. For best results, use a clean mesh with its feet near the ground and its forward direction aligned to the app's expected axis.

01 / LOAD A MODEL

Use IMPORT or the FILE panel to load GLB/GLTF, OBJ or a saved PROFILE JSON project. Use DEMO RIG to restore the built-in humanoid example. OBJ imports are static geometry and need a generated rig.

02 / BUILD + CHECK THE RIG

Open RIG, choose a preset, adjust Rig width if needed, then press BUILD RIG + BIND. Inspect the bone tree and joints. The procedural preset is a starting skeleton, not an automatic guarantee of production-ready topology or weights.

03 / POSE + DEFORM

Select a bone in the viewport or Scene tree. Use FK / Pose to rotate individual joints or IK Targets to move a chain endpoint. Open SKIN to re-solve, smooth or paint weights if the mesh pinches or stretches incorrectly.

04 / CREATE MOTION

Choose Walk, Run, Idle, Jump, Sneak or Strut under MOTION. Adjust speed and stride, preview it, then use BAKE TO KEYS to convert procedural motion to editable keyframes. Use the timeline and Graph Editor for refinement.

Important: deformation quality depends on mesh topology, skeleton placement and skin weights. Always test extreme poses, foot contacts and the exported file in your target 3D application or engine.

Rig preset tutorials

Each preset builds a different joint layout. The library includes bipeds, mecha, quadrupeds, scorpion mecha, winged dragons and vehicles. Set spine density before building; use vertex-to-joint mode to extend generated rigs for unusual silhouettes. Presets are editable starting points for compatible meshes.

2 LEGS

Humanoid / Biped

For people, stylized characters and upright creatures with two arms and two legs.

How to use

  1. Load a humanoid mesh facing the expected forward direction, or press DEMO RIG.
  2. Choose Humanoid / Biped and press BUILD RIG + BIND.
  3. Check hips, spine, head, shoulders, elbows, wrists, knees and ankles in the bone tree.
  4. Select an arm or leg bone; use FK for posing or create an IK chain for end-effector control.
  5. Test a walk pose and inspect shoulders, hips and knees for weight artifacts.
Best for standard biped motion. Hand/finger articulation depends on the generated skeleton or imported rig.
ARMORED BIPED

Mecha Torso / Biped

For robots, armored characters and mechanical suits with a reinforced core and actuator-like joints.

How to use

  1. Load a robot mesh with its torso centered around the body root.
  2. Choose Mecha Torso / Biped and build the rig.
  3. Inspect the torso/core and limb joint placement; adjust width if the skeleton is too narrow or broad.
  4. Use FK to articulate mechanical segments; add IK to feet or hands where endpoint control is useful.
  5. Test hard-surface intersections at shoulders, elbows, hips and knees.
Rigid armor may need rigid or carefully painted weights. A single smooth skin bind will not automatically preserve every mechanical panel gap.
ADAPTIVE SKELETON

Multipurpose Spine + Vertex Joint Creator

Use a denser spine for serpentine, elongated, flexible or unusual characters. Add joints directly at picked mesh vertices to create controls for custom silhouettes.

How to use

  1. Set Spine segments from 3–14 before building; more segments provide finer articulation but need careful weights.
  2. Press BUILD RIG + BIND to regenerate the selected preset with that spine density.
  3. Select a bone in the tree to use it as the parent for a custom joint.
  4. Press CREATE JOINT FROM VERTEX, then click the desired point on the mesh. The nearest triangle vertex is used.
  5. Re-solve weights and inspect the new joint’s influence; rename or reposition it by editing the project data if needed.
Custom vertex joints are added to the current generated rig and weights are recalculated. Use sensible joint spacing; too many close joints can cause unstable-looking deformation.
WINGS + TAIL

Dragon / Winged Creature

Creates a long-bodied creature skeleton with articulated forelimbs, hind limbs, paired multi-joint wings and a segmented tail.

How to use

  1. Set the mesh facing the expected +Z direction, with its body centered and feet near ground level.
  2. Choose Dragon / Winged Creature + Tail, set the desired spine segment count, then build.
  3. Inspect the left/right wing chains from shoulder through wrist and finger-like wing struts.
  4. Create or use IK controls for limb chains; pose wing joints with FK for folding and spread poses.
  5. Check membrane deformation manually in Skin and paint weights around wing roots and tail transitions.
This generates a control skeleton, not wing membranes or automatic aerodynamic animation. Mesh topology and weights determine deformation quality.
CHASSIS + RUNNING GEAR

Vehicle / Chassis + Wheels

Builds a mechanical hierarchy for a vehicle body, four suspension corners, wheel rotation, steering pivots and optional turret/door anchor points.

How to use

  1. Load a vehicle mesh with its length aligned to the expected forward axis and wheels near the ground.
  2. Choose Vehicle / Chassis + Wheels + Steering and build.
  3. Inspect chassis, axle, suspension and wheel joints; select a wheel joint to rotate it for a roll test.
  4. Use FK for wheel rotation and steering pivots. Add vertex joints to connect custom parts such as doors, mirrors or articulated equipment.
  5. Re-solve weights, then test wheels and chassis independently before keyframing.
A single merged vehicle mesh may deform poorly under skeletal skinning. For rigid parts, separate object parenting or rigid per-part weights are preferable; this preset is a starter hierarchy.
4 LEGS

Quadruped / Four Legs

For animal-like bodies with forelegs, hind legs, a spine and a tail/body line where supported by the preset.

How to use

  1. Align the animal body with its feet near the ground and facing the selected forward direction as described by the rig selector hint.
  2. Choose Quadruped / Four Legs and build the rig.
  3. Check front and rear hip/shoulder positions, knee/hock bends and foot endpoints.
  4. Use the leg IK targets to place each foot; adjust pole controls to guide bend direction.
  5. Test stance and walk poses, then fix weight transitions around shoulders, hips and belly.
Quadruped proportions vary widely. Long-backed, hoofed, digitigrade or unusual animals may need manual joint adjustment and custom weights.
6 LEGS + TAIL

Scorpion Mecha / Six Legs + Tail

For a mechanical scorpion with three pairs of legs, a segmented articulated tail and a stinger endpoint.

How to use

  1. Align the chassis centrally, keep the six feet close to the ground and align the model to the selected forward axis.
  2. Choose Scorpion Mecha / Six Legs + Tail and build the rig.
  3. Inspect left/right leg pairs and tail segments tail_seg_01–10 plus tail_stinger.
  4. Select a leg IK chain and move its target to test reach; use the pole control to influence knee bend.
  5. Select the tail IK chain and move its target to articulate the distal tail and stinger; pose individual tail bones with FK for fine adjustments.
  6. Preview motion and check all six feet, tail clearance and body balance before baking keys.
The tail and leg chains are controllable, but realistic contact, balance and collision avoidance still require manual review.

Select

Choose a bone, IK target or pole control. Use the Scene bone tree when overlapping joints are hard to click. The selected bone name appears in the HUD and RIG panel.

FK / Pose

Forward kinematics rotates the selected joint and carries its descendants. Select a bone, choose ROTATE, then use the transform gizmo or Rot X/Y/Z sliders. MOVE HIPS moves the root/hips rather than rotating a joint.

IK Targets

Inverse kinematics solves a chain toward a target. Create a chain from a selected bone with Create IK from selected bone, select a chain in the IK list, and move its target. IK/FK Blend mixes between the chain solution and FK pose; Toggle enables/disables the chain, Delete removes it, and Snap places its target at the endpoint.

Pole controls

A pole vector helps determine which way a multi-joint limb bends. Move the pole control to steer a knee or elbow away from an unwanted flip. Keep the pole off the limb's straight line and test the full range of movement.

Rig width

Controls the generated rig's lateral scale/width before building. Use small increments, then rebuild and inspect joint alignment. It does not replace manual per-joint placement for nonstandard anatomy.

Reset + Mirror

Reset bone returns the selected bone to its rest rotation. Reset pose restores the overall pose. Mirror L→R copies left-side pose values to the right; Mirror R→L does the reverse. Check asymmetrical rigs after mirroring.

Bind / Re-solve weights

Skin weights determine how strongly each vertex follows each bone. Press RE-SOLVE WEIGHTS after rig changes to calculate a new distance-based distribution. Treat the result as a starting point and inspect bends.

Weight Paint tool

Select a bone, switch to Weight Paint in the left toolbar, then drag over the mesh. Add increases the selected bone's influence and Subtract reduces it. Radius sets brush reach; Strength sets the amount applied per stroke.

Smooth

Smooth blends abrupt weight changes to reduce visible creases. Use it gently around shoulders, hips and other bending zones, then test again. Excessive smoothing can cause unwanted deformation or loss of rigid separation.

Weights: ON / OFF

Toggle the weight-color display to inspect influence distribution. Choose a bone and check whether nearby vertices show a plausible falloff. The color view is diagnostic; it does not itself edit the weights.

If the mesh collapses, stretches or slides at a joint, inspect the joint location first, then weights. Re-solving weights may overwrite custom paint, so save a project copy before doing so.

Procedural motion presets

Walk creates a standard gait; Run increases the action; Idle adds subtle movement; Jump adds a vertical action; Sneak lowers and softens movement; Strut exaggerates the gait. Creature rigs may interpret these as generalized procedural poses rather than species-specific motion capture.

Speed + Stride

Speed changes the motion rate. Stride changes the extent of the gait. Preview before baking. Use modest changes first to avoid feet sliding or extreme joint angles.

Preview + Bake to Keys

Preview evaluates the chosen procedural motion. BAKE TO KEYS writes the motion into timeline keyframes so you can scrub, edit and export it. Choose Pose or Keys as the animation source depending on whether you want the live pose or stored animation.

Timeline + keyframes

Click or scrub the timeline to change frame. KEY inserts a key at the current frame; DEL KEY removes the key at that frame; CLEAR clears keys. LOOP ON toggles repeat playback. Space plays/pauses and K inserts a key.

Graph Editor

Press GRAPH EDITOR to switch from the timeline to the curve view. Select a channel (Hips Y or Selected Bone Rot X), then drag a plotted key to edit its value. Choose Linear, Smooth S-Curve, Ease In/Out, Ease In-Out or Constant/Step interpolation to control transitions.

Clip source

Imported GLB/GLTF animation clips appear under Add-on Animations when available. These clips are listed from the imported file; the built-in procedural controls and the app's keyframe timeline are separate editing paths.

Import

Use IMPORT or IMPORT GLB / OBJ / PROJECT. GLB/GLTF can contain meshes, skinning and animation clips; OBJ is geometry-only; JSON loads a saved PROFILE project. Imported skinned GLBs retain their existing skeleton and weights when successfully adopted.

Export Animated GLB

Use EXPORT GLB or EXPORT ANIMATED GLB to write the rig/mesh and keyed animation in glTF binary form. Re-import the result or test it in your target app to verify materials, skeleton, weights and animation playback.

Save Project (.json)

Save a project JSON to preserve the editable scene/rig data and keyframes supported by this application. Keep the source mesh and project together; a JSON project is not a replacement for a portable mesh/animation export.

New + Demo

NEW clears the current working scene; save first if needed. DEMO RIG loads the built-in humanoid mesh and rig for learning the interface without importing a character.

File format support can vary by asset complexity. Always verify exported deformation and animation in a separate viewer or engine before delivery.

Motion Studio · Color-coded editor workflow

Work on the same loaded model: start with rigging and skinning in the main viewport, then select MOTION STUDIO in the timeline. Use the colored module ribbon to open the corresponding tools. Return using MAIN RIGGING APP; no second import should be necessary.

PURPLE / LAYERS + NLA

  1. Key a pose in the base timeline.
  2. Create a named take and add an NLA strip.
  3. Set strip position, speed, fade and bone masks.
  4. Inspect composed playback before exporting GLB.

ORANGE / LOCOMOTION + PATHS

  1. Choose Walk, Run, Idle or another available procedural driver.
  2. Set speed and stride, then preview or bake.
  3. Add timed XYZ root waypoints and preview the spline path.
  4. Inspect foot contacts; the contact solver is not force validated.

CYAN / CONSTRAINTS

  1. Select a bone and a relationship target.
  2. Add aim, rotation-copy or joint-limit constraints.
  3. Order the stack and check for dependency cycles.
  4. Review the final pose under IK and during playback.

GREEN / LOOKDEV + CAMERAS

  1. Open Motion Viewer and fit the loaded model.
  2. Add camera keys, shot ranges and transitions.
  3. Scrub the sequence and inspect cut timing.
  4. Capture PNG frames or record WebM when the browser supports it.
Technical boundary: advanced constraint baking, export interoperability and cross-rig IK/contact behavior require full browser-based validation. The hosted edition currently fetches Three.js from a CDN.

VIS · Live inspection and telemetry

Open VIS from the main application. FPS, vertex counts, bone counts, selected-joint rotation and sampled skin-weight statistics come from the currently loaded scene. Studio module counters summarize editing state where it is accessible.

01 / SKIN AUDIT

Review normalized influence percentages, invalid samples and average bone influence. Rigid scorpion shells should use a single effective bone influence per connected mechanical part. Weight validity alone does not guarantee correct mechanical pivots.

02 / LIVE MOTION SIGNAL

The cyan graph shows selected-joint angular deviation. The orange trace displays frame-time estimates. Pause telemetry to inspect a moment without stopping the animation itself.

03 / COMPOSITION STATUS

Check layers, strips, constraints, paths and camera shots while authoring. Counts are informative diagnostics, not evidence that an exported asset has passed interoperability tests.

04 / EXPORT REVIEW

Run Skin Audit, Motion Audit and GLB verification where available, then reopen the exported asset in a second compatible application to inspect deformation, curves and clips.

Engineering evaluation · boundaries and release checks

PROFILE offers experimental browser-based rigging, editing and animation tools. The presence of a module is not proof of validated anatomical, mechanical, physical or exported-animation accuracy.

CHECK BEFORE EXPORT

  1. Confirm imported axes, scale and pivots.
  2. Move every expected leg and tail segment independently.
  3. Inspect skin weights, deformation and IK reach.
  4. Scrub NLA transitions and constraint results.
  5. Export, reimport and compare clips and materials.

KNOWN LIMITS

Ground contact is not an independently validated contact-force or friction simulation. Blender Rigify interchange transfers guides rather than running its Python generator. The current hosted HTML uses network Three.js dependencies. Complete real-browser regression testing and professional certification remain outstanding.
